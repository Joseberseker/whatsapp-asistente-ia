# WhatsApp Asistente IA

Asistente de WhatsApp con IA construido sobre la **WhatsApp Cloud API de Meta** (número de prueba, sin costo), con un **núcleo genérico** al que se le enchufan **módulos de negocio** y un **dashboard** para operarlo.

> 🚧 En construcción. Ver el roadmap abajo.

## Stack
Python · FastAPI · WhatsApp Cloud API · Gemini (function calling) · SQLite · HTMX

## Roadmap
- [ ] Webhook de WhatsApp (verificación, firma, envío)
- [ ] Memoria de conversación + ventana de 24 h
- [ ] Agente con Gemini y tools por módulo
- [ ] Módulo: recordatorios
- [ ] Dashboard
- [ ] Módulos siguientes: citas, FAQ con RAG, traspaso a humano, tienda, campañas
